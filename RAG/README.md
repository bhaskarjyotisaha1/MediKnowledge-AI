# MediAI – Healthcare RAG Chatbot

## About
MediAI is an AI-powered healthcare chatbot built using Retrieval-Augmented Generation (RAG). It allows users to interact with healthcare-related PDF documents and retrieve relevant information through natural language questions.

The chatbot processes PDF documents, extracts text, splits it into smaller chunks, generates embeddings, and stores them in a vector database. When a user asks a question, the system retrieves relevant information and generates a contextual response using a Large Language Model (LLM).

## Purpose
The purpose of this folder is to store healthcare-related PDF documents that serve as the knowledge base for the MediAI chatbot.

## Supported Documents
- Healthcare reference materials
- Medical textbooks
- Pharmaceutical documents
- Clinical and healthcare guidelines
- Other relevant healthcare PDF documents

## Document Processing Workflow
1. Upload healthcare PDF documents.
2. Extract text from the PDF files.
3. Split extracted text into manageable chunks.
4. Generate vector embeddings.
5. Store embeddings in a vector database.
6. Retrieve relevant information based on user queries.
7. Generate context-based responses using an LLM.

## Important Notes
- Only use reliable and relevant healthcare reference materials.
- Avoid uploading confidential patient information.
- Ensure documents are legally permitted for use.
- Chatbot responses are intended for educational and informational purposes only and should not replace professional medical advice.
